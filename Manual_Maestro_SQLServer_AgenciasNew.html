Despliegue, Migración y Operación con Microsoft SQL Server — AgenciasNew

REGLA FUNDAMENTAL DE DESPLIEGUE:
El instalador de la aplicación NUNCA ejecuta CREATE DATABASE ni requiere permisos de creación de base de datos. La infraestructura o cliente es responsable de crear o restaurar la base de datos manualmente antes de configurar la aplicación.

1. Reglas Fundamentales de Arquitectura y Principios de Despliegue

1.1 Regla Primordial de Lógica en Base de Datos (Database-First)

Todo cálculo, proceso de negocio, liquidación de comisiones, consulta de listado, validación o mutación de datos en AgenciasNew DEBE realizarse obligatoriamente a través de Procedimientos Almacenados (SPs), Funciones SQL y Tablas de Base de Datos.

1.2 Prohibición Absoluta de CREATE DATABASE en Instaladores

  • El instalador de SQL Server NUNCA debe ejecutar CREATE DATABASE ni requerir permisos administrativos para crear bases de datos.
  • La infraestructura/cliente es la única responsable de crear o restaurar la base de datos manualmente.

2. Los 6 Entregables Oficiales del Proyecto

Entregable Nombre del Componente / Archivo Descripción y Función
01 Instalador PostgreSQL Instalador local PostgreSQL intacto sin cambios funcionales.
02 Instalador SQL Server (setup_db_sqlserver.js) Instala la aplicación y valida la conexión a la base existente (Sin CREATE DATABASE).
03 Base SQL Server Inicial (deploy/BaseLimpia/Korex_SQLServer_Inicial_1.0.bak) Backup estructurado en blanco con semillas maestras, libre de datos de clientes.

3. Generación del Backup Inicial en Blanco (Korex_SQLServer_Inicial_1.0.bak)

Para generar el backup .BAK inicial ejecute desde la consola o con 1 clic:

GenerarBaseInicialBakSqlServer.bat

4. Manual Paso a Paso para Clientes Nuevos (Escenario A)

  1. Copiar el Backup: Colocar Korex_SQLServer_Inicial_1.0.bak en la carpeta de backups del servidor.
  2. Restaurar en SSMS: Ejecutar el script T-SQL: 
    RESTORE DATABASE [Korex_colaereo]
FROM DISK = N'C:\Backup\Korex_SQLServer_Inicial_1.0.bak'
WITH FILE = 1,
MOVE N'Korex_SQLServer_Inicial_Temp' TO N'C:\SQLData\Korex_colaereo.mdf',
MOVE N'Korex_SQLServer_Inicial_Temp_log' TO N'C:\SQLData\Korex_colaereo_log.ldf',
NOUNLOAD, STATS = 5;
GO
  3. Crear Usuario SQL: Asignar rol db_owner a korex_user.
  4. Ejecutar Instalador: Iniciar Korex_SQLServer_Setup.exe e ingresar credenciales.

5. Manual Paso a Paso para Clientes Existentes (Migración desde PostgreSQL)

Para migrar con 1 solo clic ejecute desde la raíz del proyecto:

Ejecutar_Migracion_SQLServer.bat

Este script transfiere automáticamente los datos desde PostgreSQL a SQL Server manteniendo la coincidencia de IDs y corre el auditor de integridad.
